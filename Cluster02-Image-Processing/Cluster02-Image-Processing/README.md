# Unit 2: Digital Image Processing

## Problem Statement
Implement image enhancement, transformation, filtering, and quantitative restoration analysis using spatial domain operations.

## Objectives
- Perform point-processing operations: Negative, Binary Thresholding, Contrast Adjustment.
- Implement spatial neighborhood filters: Mean, Median, Gaussian, and 2D Convolution Sharpening.
- Quantitatively evaluate noise restoration performance using MSE, PSNR, and SSIM.

## Methodology & Metrics
- **Mean Squared Error (MSE)**: Quantifies cumulative squared pixel error between reference and restored outputs.
- **PSNR**: Ratio of maximum possible pixel signal power to degrading noise power.
- **SSIM**: Models perception-based structural degradation over simple numerical difference.

- `outputs/image_processing_grid.png`: Complete 2x4 visual comparison grid of transformations and spatial filters.
